# Roadmap проекта LinkAnalyzer — План и этапы разработки

## Цель проекта
Создать асинхронный сервис анализа веб-страниц, принимающий список URL
и выполняющий фоновый анализ, с целью проверки доступности ресурса, выявления проблемных URL, 
сбора технических метрик и получения информации о структуре и компонентах HTML-документов.

Сервис ориентирован на практическое использование при разработке, отладке и техническом анализе веб-ресурсов.

---


## Роль файла

Данный документ отражает фактическое состояние проекта LinkAnalyzer, выполненные
